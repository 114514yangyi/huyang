1. 深度神经网络基础架构

深度神经网络 (DNN)

原理：由多个隐藏层组成的神经网络，通过层级变换实现复杂函数逼近。

# 简单DNN实现
import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense, Dropout

model = Sequential([
    Dense(128, activation='relu', input_shape=(input_dim,)),
    Dropout(0.3),
    Dense(64, activation='relu'),
    Dense(32, activation='relu'),
    Dense(num_classes, activation='softmax')
])

搭建要点：

  • 层数深度决定模型容量
  • 激活函数引入非线性
  • Dropout防止过拟合

from tensorflow.keras.layers import Conv2D, MaxPooling2D, Flatten

model = Sequential([
    Conv2D(32, (3, 3), activation='relu', input_shape=(28, 28, 1)),
    MaxPooling2D((2, 2)),
    Conv2D(64, (3, 3), activation='relu'),
    MaxPooling2D((2, 2)),
    Conv2D(64, (3, 3), activation='relu'),
    Flatten(),
    Dense(64, activation='relu'),
    Dense(10, activation='softmax')
])

关键组件：

  • 卷积层：特征提取，3×3或5×5滤波器
  • 池化层：降维，保留主要特征（MaxPooling, AveragePooling）
  • 全连接层：最终分类

3. 循环神经网络 (RNN) 和 LSTM

RNN原理

时序数据处理：隐藏状态传递历史信息

$$ h_t = \tanh(W_{hh}h_{t-1} + W_{xh}x_t + b_h) $$

LSTM (长短期记忆网络)

解决梯度消失：门控机制控制信息流

LSTM三个门：

  • 遗忘门：决定丢弃哪些信息
  • 输入门：决定更新哪些信息
  • 输出门：决定输出哪些信息

import torch
import torch.nn as nn
import torch_geometric.nn as pyg_nn

class GNN(nn.Module):
    def __init__(self, input_dim, hidden_dim, output_dim):
        super(GNN, self).__init__()
        self.conv1 = pyg_nn.GCNConv(input_dim, hidden_dim)
        self.conv2 = pyg_nn.GCNConv(hidden_dim, output_dim)
  
    def forward(self, x, edge_index):
        x = self.conv1(x, edge_index)
        x = torch.relu(x)
        x = self.conv2(x, edge_index)
        return x

消息传递机制：

  1. 节点收集邻居信息
  2. 聚合函数（mean, sum, max）
  3. 更新节点特征

from transformers import Transformer

class TransformerModel(nn.Module):
    def __init__(self, vocab_size, d_model, nhead, num_layers):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, d_model)
        self.transformer = nn.Transformer(
            d_model=d_model, nhead=nhead, num_encoder_layers=num_layers,
            num_decoder_layers=num_layers
        )
        self.fc = nn.Linear(d_model, vocab_size)

自注意力公式：

$$ \text{Attention}(Q,K,V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V $$

GloVe (Global Vectors)

基于共现矩阵：统计全局词共现信息

$$ J = \sum_{i,j=1}^V f(X_{ij})(w_i^T \tilde{w}_j + b_i + \tilde{b}_j - \log X_{ij})^2 $$

自回归 vs 自编码

特性 自回归 (GPT) 自编码 (BERT)
方向性 单向 双向
适合任务 文本生成 文本理解
注意力掩码 因果掩码 全注意力

# 知识蒸馏损失
def distillation_loss(student_output, teacher_output, temperature=2.0):
    student_logits = student_output / temperature
    teacher_probs = torch.softmax(teacher_output / temperature, dim=-1)
    return nn.KLDivLoss()(torch.log_softmax(student_logits, dim=-1), teacher_probs)

蒸馏方法：

  • 响应蒸馏：模仿输出分布
  • 特征蒸馏：模仿中间层特征
  • 关系蒸馏：模仿样本间关系
