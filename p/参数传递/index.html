参数传递

Created by: Hu Yang Created time: November 9, 2023 10:06 AM Tags: Guides

在Java中，参数传递可以分为值传递和引用传递两种方式。下面我将为你提供一些例子来说明这两种传递方式的区别。

值传递（Pass-by-Value）：

在值传递中，方法接收的是实际参数值的一个拷贝。修改形参的值不会影响实际参数的值。

示例1：基本数据类型的值传递

public class Main {
    public static void main(String[] args) {
        int num = 10;
        System.out.println("调用方法前：" + num);
        increment(num);
        System.out.println("调用方法后：" + num);
    }

    public static void increment(int value) {
        value = value + 1;
        System.out.println("方法内部：" + value);
    }
}

输出：

1
2
3

调用方法前：10
方法内部：11
调用方法后：10

在上述示例中，increment()方法接收的是变量num的值的拷贝。在方法内部，对形参value的修改不会影响到实际参数num的值。

引用传递（Pass-by-Reference）：

在引用传递中，方法接收的是实际参数的引用。修改形参的值会影响到实际参数的值。

示例2：引用类型的引用传递

public class Main {
    public static void main(String[] args) {
        int[] arr = {1, 2, 3};
        System.out.println("调用方法前：" + Arrays.toString(arr));
        modifyArray(arr);
        System.out.println("调用方法后：" + Arrays.toString(arr));
    }

    public static void modifyArray(int[] array) {
        array[0] = 10;
        System.out.println("方法内部：" + Arrays.toString(array));
    }
}

输出：

1
2
3

调用方法前：[1, 2, 3]
方法内部：[10, 2, 3]
调用方法后：[10, 2, 3]

在上述示例中，modifyArray()方法接收的是数组arr的引用。在方法内部，对形参array所引用的数组进行的修改会直接影响到实际参数arr所引用的数组。

需要注意的是，在引用传递中，虽然方法内部可以修改引用所指向的对象的内容，但如果在方法内部将形参重新指向一个新的对象，不会对实际参数产生影响。

示例3：引用类型重新指向新对象的引用传递

public class Main {
    public static void main(String[] args) {
        StringBuilder sb = new StringBuilder("Hello");
        System.out.println("调用方法前：" + sb);
        modifyStringBuilder(sb);
        System.out.println("调用方法后：" + sb);
    }

    public static void modifyStringBuilder(StringBuilder str) {
        str.append(" World");
        str = new StringBuilder("New");
        System.out.println("方法内部：" + str);
    }
}

输出：

1
2
3

调用方法前：Hello
方法内部：New
调用方法后：Hello World

在上述示例中，modifyStringBuilder()方法接收的是sb的引用。在方法内部，对形参str所引用的StringBuilder对象进行的修改会影响到实际参数sb所引用的对象。但当将形参重新指向一个新的StringBuilder对象时，不会对实际参数产生影响。

通过上述例子，你可以更好地理解Java中值传递和引用传递的概念以及它们之间的区别。
