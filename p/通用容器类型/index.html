通用容器类型

Created by: Hu Yang Created time: October 24, 2023 11:01 AM Tags: Guides, 容器

下面是所提及的 Java 容器类型的常用函数以及对应的头文件（即 Java 类的导入语句）：

  1. Vector

    • 头文件：import java.util.Vector;

    • 常用函数：

      • add(E element)：向向量末尾添加元素。
      • get(int index)：获取指定索引位置的元素。
      • set(int index, E element)：将指定索引位置的元素替换为新元素。
      • remove(int index)：移除指定索引位置的元素。
      • size()：获取向量的大小。

    • 用例：

      import java.util.Vector;

Vector<Integer> vector = new Vector<>();
vector.add(5);
vector.add(2);
vector.add(8);

int element = vector.get(1);
vector.set(0, 10);
vector.remove(2);
int size = vector.size();

  2. Stack

    • 头文件：import java.util.Stack;

    • 常用函数：

      • push(E element)：将元素推入栈顶。
      • pop()：移除并返回栈顶元素。
      • peek()：返回栈顶元素但不移除。
      • empty()：判断栈是否为空。
      • search(Object element)：搜索元素在栈中的位置。

    • 用例：

      import java.util.Stack;

Stack<String> stack = new Stack<>();
stack.push("apple");
stack.push("banana");
stack.push("orange");

String element = stack.pop();
String topElement = stack.peek();
boolean isEmpty = stack.empty();
int index = stack.search("apple");

  3. ArrayDeque

    • 头文件：import java.util.ArrayDeque;

    • 常用函数：

      • addFirst(E element)：在双端队列的开头插入元素。
      • addLast(E element)：在双端队列的末尾插入元素。
      • getFirst()：获取双端队列的第一个元素。
      • getLast()：获取双端队列的最后一个元素。
      • removeFirst()：移除并返回双端队列的第一个元素。
      • removeLast()：移除并返回双端队列的最后一个元素。

    • 用例：

      import java.util.ArrayDeque;

ArrayDeque<Integer> deque = new ArrayDeque<>();
deque.addFirst(5);
deque.addLast(2);
deque.addLast(8);

int firstElement = deque.getFirst();
int lastElement = deque.getLast();
int removedElement = deque.removeFirst();

  4. HashSet

    • 头文件：import java.util.HashSet;

    • 常用函数：

      • add(E element)：向集合中添加元素。
      • contains(Object element)：判断集合是否包含指定元素。
      • remove(Object element)：从集合中移除指定元素。
      • size()：获取集合的大小。

    • 用例：

      import java.util.HashSet;

HashSet<String> set = new HashSet<>();
set.add("apple");
set.add("banana");
set.add("orange");

boolean contains = set.contains("banana");
set.remove("apple");
int size = set.size();

  5. HashMap

    • 头文件：import java.util.HashMap;

    • 常用函数：

      • put(K key, V value)：向映射中添加键值对。
      • get(Object key)：根据键获取对应的值。
      • containsKey(Object key)：判断映射是否包含指定的键。
      • remove(Object key)：根据键移除键值对。
      • size()：获取映射中键值对的数量。

    • 用例：

      import java.util.HashMap;

HashMap<String, Integer> map = new HashMap<>();
map.put("apple", 5);
map.put("banana", 3);
map.put("orange", 8);

int value = map.get("banana");
boolean containsKey = map.containsKey("apple");
map.remove("orange");
int size = map.size();

  6. Queue

    • 头文件：import java.util.Queue;

    • 常用函数：

      • add(E element)：向队列末尾添加元素。
      • offer(E element)：向队列末尾添加元素。
      • remove()：移除并返回队列头部的元素。
      • poll()：移除并返回队列头部的元素。
      • peek()：返回队列头部的元素但不移除。
      • element()：返回队列头部的元素但不移除。

      import java.util.LinkedList;
import java.util.Queue;

Queue<String> queue = new LinkedList<>();
queue.add("apple");
queue.offer("banana");
queue.offer("orange");

String removedElement = queue.remove();
String polledElement = queue.poll();
String peekedElement = queue.peek();
String element = queue.element();

这些是所提及的 Java 容器类型的常用函数以及对应的头文件。根据具体需求，您可以选择适当的容器类型和函数来处理数据。请注意，头文件的导入语句可以根据需要放置在代码文件的开头。
