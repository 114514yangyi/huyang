项目经历

求职RAG系统 - 项目组长 (软件工程3课程项目)

在2025年软件工程3课程项目中,作为项目组⻓,我主导并管理了一个6人团队,成功开发了求职智能问答系统。我负责项目全流程管理,包括系统架构设计,采用 React 前端 + FastAPI 后端的微服务架构。在技术实现上,我设计并构建了基于 LangChain 框架与 DeepSeek 大语言模型的 RAG(检索增强生成)查询链,实现了系统的核心AI功能。此外,我独立承担了后端服务搭建及前后端接口设计,最终交付了支持自然语言查询的系统原型,有力地验证了 RAG 技术在实际应用场景中的工程可行性。

AI人脸识别系统 - 核心开发 (江苏省大学生计算机设计大赛)

在2024年计算机设计大赛中,我作为核心开发者,主导并完成了竞赛项目的后端与前端开发工作,助力团队荣获省级二等奖。我负责将人脸识别算法模型进行技术解耦与封装,利用FastAPI 框 架 构 建 了 高 性 能 、 可 扩 展 的 RESTful API 接 口 。 同 时 , 我 独 立 完 成 了 基 于HTML/CSS/JavaScript 的基础用户交互界面,实现了前后端数据的无缝对接。该项目不仅成功将前沿 AI 模型落地为可用的软件产品,也充分展示了我在 API 设计、前后端通信和系统集成方面的扎实工程能力。

Shapez游戏QT开发

在《异形工厂》项目开发中,我熟练掌握了 C++ 面向对象和泛型编程范式,通过构建如Gamestate, Grid 和 Center 等核心模块,实现了清晰、可扩展的程序架构。我运用了 C++ 标准模板库(STL)中的多种容器,包括 , , , 和 来高效管理游戏数据。该项目不仅锻炼了我解决复杂逻辑问题的能力,例如在地图上实现设备放置、物品运输和切割处理,还要求使用第三方 C++ 图形库QT实现可视化的工厂运行效果,加深了对 GUI 开发的理解。
